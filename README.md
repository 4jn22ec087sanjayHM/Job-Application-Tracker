# Job Application Tracker

A full-stack web application designed to help job seekers manage, organize, and track their job applications from a single dashboard.

The project is being developed as a real-world Python/JavaScript full-stack application with a REST API, PostgreSQL database, authentication, job application management, search/filtering, and dashboard features.

## 🎯 Project Objective

The goal of this project is to build a practical job application management system where users can:

- Create an account
- Log in securely
- Add job applications
- Track application status
- Update application information
- Delete applications
- Search and filter applications
- Sort applications
- View application statistics
- Manage their job search from a centralized dashboard
